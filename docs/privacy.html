수집하는 정보

아빠의 기록장은 서버 계정, 광고 식별자, 분석 이벤트를 수집하지 않습니다. 사용자가 작성한 글, 가족 구성원 이름, 태그, 음성 파일은 앱 기능 제공을 위해 사용자의 기기 내부에 저장됩니다.

권한 사용

마이크 권한은 사용자가 음성 기록을 직접 남길 때만 사용합니다. 녹음 파일은 기기 내부 앱 저장소에 보관됩니다.

제3자 제공 및 서버 전송

앱은 광고 SDK, 분석 SDK, 클라우드 동기화, 외부 서버 업로드 기능을 포함하지 않습니다.

백업

민감한 가족 기록 보호를 위해 Android 자동 백업과 기기 이전 백업에서 앱 데이터를 제외하도록 설정합니다. 별도 보관이 필요한 경우 사용자가 직접 앱 내 텍스트 복사 기능을 사용할 수 있습니다.

문의

문의는 GitHub 저장소 이슈 또는 프로필에 공개된 연락 경로를 통해 남길 수 있습니다.
